# All-Basis-Items

Every item, recipe and item tag of **Minecraft 26.2** in one plain text file, exported from the server's data generator.

## The list

[`26.2/items_und_rezepte.txt`](26.2/items_und_rezepte.txt) has three parts:

| Part | Content | Example |
|---|---|---|
| `## ITEMS` | every item id, sorted | `acacia_boat` |
| `## REZEPTE` | every recipe: result and count, recipe type, ingredients | `torch x4 <- crafting_shaped: coal\|charcoal, stick` |
| `## TAGS` | every item tag and its members | `#logs: …` |

In the recipes, `|` means "one of these" and `#` marks an item tag. The `minecraft:` prefix is left out everywhere.

## Make it yourself (other versions too)

1. Run the data generator of the server jar of the version you want:

   ```bash
   java -DbundlerMainClass=net.minecraft.data.Main -jar server.jar --all
   ```

   It writes a `generated` folder next to the jar.
2. Run [`export.py`](26.2/export.py) in that same folder (Python 3, no packages needed):

   ```bash
   python export.py
   ```

   It reads `generated/reports/registries.json`, `generated/data/minecraft/recipe` and `generated/data/minecraft/tags/item`, and writes `items_und_rezepte.txt`.
